# M5 bulk-import-validation

## 背景 / 要解决的问题

句子池需要持续导入和修正。首版支持 CSV/JSON 批量导入、字段映射、预校验、导入结果展示和失败行下载，避免超级管理员只能逐条维护。

## 规则

1. 批量导入支持 CSV 和 JSON 文件。
2. 导入流程分为上传文件、字段映射、预校验、确认导入、结果查看。
3. 字段映射必须覆盖句子文本、难度、目标词、sceneTag、音频 URL、`sceneId`、`courseId`、`sortOrder` 中可导入字段。
4. 必填字段最少包含句子文本；其他字段可为空并进入草稿。
5. 预校验必须识别：缺少必填字段、字段类型错误、目标词格式错误、scene/course 不存在、同课排序冲突、重复句子文本。
6. 导入模式支持新增和按 `sentenceId` 更新；未提供 `sentenceId` 时默认新增。
7. 预校验通过前不得执行正式导入。
8. 导入结果必须展示新增、更新、失败、跳过数量，并提供失败行下载。

## 交互

- 超级管理员进入批量导入 -> 上传 CSV/JSON -> 系统解析字段。
- 超级管理员确认字段映射 -> 点击预校验 -> 系统展示错误和警告。
- 超级管理员修正文件或确认导入 -> 系统执行导入 -> 展示结果摘要和失败行下载入口。
- 超级管理员从结果页跳转到句子池 -> 自动带入本次导入批次筛选。

## 视觉 / UI 布局

- 批量导入采用步骤条：上传、映射、预校验、导入、结果。
- 字段映射页左侧为文件字段，右侧为系统字段。
- 预校验结果按错误和警告分组；错误阻止导入，警告允许确认导入。

## 边界行为

- 文件为空或格式无法解析时，停留上传页并展示原因。
- 单次文件过大时，提示拆分导入；具体大小限制由 @tech-lead / @be-dev 确认。
- 部分行失败时，不回滚已成功行，但结果中必须能下载失败行。
- 导入中断时，结果页必须展示可确认的最终状态或提示重新查询。

## 验收 checklist

- [ ] 支持 CSV/JSON 上传。
- [ ] 支持字段映射和预校验。
- [ ] 预校验覆盖必填、类型、引用、排序、重复文本问题。
- [ ] 支持新增和按 `sentenceId` 更新。
- [ ] 导入结果展示新增、更新、失败、跳过数量。
- [ ] 可下载失败行并回到句子池查看本次导入数据。

## 非目标

- 不做在线 Excel 表格编辑。
- 不做第三方云盘导入。
- 不做自动翻译或自动生成句子。
