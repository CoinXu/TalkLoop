# M2 scene-management

## 背景 / 要解决的问题

场景是课程和句子的上层分类，学习端按场景聚合课程。当前句子池大量句子尚未归属场景，后台需要支持超级管理员创建、编辑、排序和控制场景状态。

## 规则

1. 场景必须包含 `sceneId`、名称、slug、描述、排序值、状态、创建时间、更新时间。
2. 场景状态使用 `draft`、`published`、`unpublished`、`archived`。
3. 已发布场景才可在学习端展示；未发布或归档场景下的课程不得在学习端展示。
4. 场景发布前必须至少包含 1 个可发布课程，否则阻止发布。
5. 场景 slug 必须唯一；修改 slug 时需提示可能影响学习端路径或缓存。
6. 归档场景前必须确认其下课程数量和已发布课程数量。
7. 已归档场景默认不在列表显示，可通过状态筛选找回。
8. 场景排序影响学习端场景展示顺序。

## 交互

- 超级管理员进入场景管理 -> 查看场景列表、状态、课程数量、已发布课程数量、排序值。
- 超级管理员新建场景 -> 填写名称、slug、描述、排序 -> 保存为草稿。
- 超级管理员编辑场景 -> 修改信息 -> 保存后列表即时更新。
- 超级管理员发布场景 -> 系统检查可发布课程数量 -> 通过后发布，失败时展示阻断原因。
- 超级管理员归档场景 -> 二次确认 -> 场景进入归档状态。

## 视觉 / UI 布局

- 场景列表按排序值升序展示，支持拖拽或输入排序值调整。
- 场景状态、课程数量、发布校验状态在列表中直接可见。
- 场景详情页展示基础信息、课程概览和最近更新时间。

## 边界行为

- 场景名称为空、slug 重复、排序值非法时禁止保存。
- 场景下存在已发布课程时，下架场景需提示学习端将不可见。
- 归档场景不硬删除其下课程和句子。
- 场景恢复为草稿后，不自动恢复课程状态。

## 验收 checklist

- [ ] 可新建、编辑、发布、下架、归档、恢复草稿场景。
- [ ] 场景列表展示课程数量和已发布课程数量。
- [ ] 场景发布前校验至少 1 个可发布课程。
- [ ] 场景 slug 唯一性被校验。
- [ ] 场景排序影响学习端展示顺序。
- [ ] 归档场景默认隐藏但可筛选查看。

## 非目标

- 不做多语言场景名称。
- 不做场景封面图管理。
- 不做场景级学习路径推荐算法。
