# M7 audio-asset-policy

## 背景 / 要解决的问题

学习端练习需要音频。首版用户会提供默认音频，因此后台需要定义音频字段、默认音频兜底、音频状态筛选和发布校验展示，保证课程能发布但风险透明。

## 规则

1. 句子音频状态分为：有真实音频、使用默认音频、缺少音频、音频不可访问。
2. 默认音频可作为发布兜底；使用默认音频的句子允许发布，但发布前必须明确展示数量和列表。
3. 真实音频字段至少区分常速音频和慢速音频；首版若只有一个默认音频，可同时作为常速和慢速兜底，需在校验中标记。
4. 句子池筛选必须支持是否有音频、是否使用默认音频、音频不可访问。
5. 超级管理员可在句子详情查看音频 URL、音频状态和默认音频兜底状态。
6. 默认音频配置变更后，依赖默认音频的课程需要重新校验。
7. 音频真实可访问性检测的技术方案由 @be-dev 确认；PRD 只要求后台展示检测结果。

## 交互

- 超级管理员在句子池筛选无音频句子 -> 批量查看或处理。
- 超级管理员打开句子详情 -> 查看常速/慢速音频字段和兜底状态。
- 超级管理员发布课程 -> 系统展示使用默认音频的句子数量和列表 -> 确认后可继续发布。
- 超级管理员查看课程编排 -> 每句显示音频状态标记。

## 视觉 / UI 布局

- 音频状态在列表中用文字标签展示：真实音频、默认音频、缺失、不可访问。
- 发布校验弹窗中单独展示“默认音频兜底”分组，避免与阻断项混在一起。
- 句子详情页音频区域展示字段值、检测状态和最近检测时间。

## 边界行为

- 缺少真实音频但存在默认音频时，不阻止发布。
- 默认音频未配置且句子缺少真实音频时，发布被阻止。
- 音频不可访问时，如果默认音频可用，发布允许但必须标记兜底。
- 默认音频变更失败时，不影响已有真实音频句子。

## 验收 checklist

- [ ] 句子可展示真实音频、默认音频、缺失、不可访问状态。
- [ ] 使用默认音频的句子允许发布。
- [ ] 发布前展示使用默认音频的句子数量和列表。
- [ ] 默认音频未配置时，缺音频句子阻止发布。
- [ ] 句子池支持音频状态筛选。
- [ ] 默认音频配置变更后相关课程需重新校验。

## 非目标

- 不做 TTS 生成任务。
- 不做音频剪辑或上传工作流。
- 不做音素级发音评分。
