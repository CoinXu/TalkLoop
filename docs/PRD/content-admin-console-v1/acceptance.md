# Content Admin Console v1 总验收清单

## A1 后台基础

- [ ] 超级管理员可访问内容后台，非超级管理员不可访问。
- [ ] 后台导航覆盖场景、课程、句子池、批量导入、发布校验/任务结果。
- [ ] 所有列表页支持分页、搜索、筛选、批量选择和状态展示。
- [ ] 批量操作展示成功、失败、跳过数量和失败原因。

## A2 场景管理

- [ ] 可新建、编辑、发布、下架、归档、恢复草稿场景。
- [ ] 场景发布前校验至少 1 个可发布课程。
- [ ] 场景排序影响学习端展示顺序。

## A3 课程管理

- [ ] 可按场景新建、编辑、发布、下架、归档、恢复草稿课程。
- [ ] 课程必须绑定一个场景。
- [ ] 课程可配置句子数最小值和最大值。
- [ ] 场景未发布时课程不可发布。

## A4 句子池

- [ ] 句子池支持 targetWord、sceneTag、课程分配状态、音频状态、难度、关键词等筛选。
- [ ] 句子详情展示基础字段、归属、音频、标注和引用信息。
- [ ] 已被练习引用的句子不可硬删除。

## A5 批量导入

- [ ] 支持 CSV/JSON 上传、字段映射和预校验。
- [ ] 预校验覆盖必填、类型、引用、排序、重复文本问题。
- [ ] 导入结果展示新增、更新、失败、跳过数量，并可下载失败行。

## A6 课程编排

- [ ] 课程编排页具备左侧句子池和右侧课程句子列表。
- [ ] 添加句子时同步写入 `sceneId`、`courseId`、`sortOrder`。
- [ ] 支持移除句子和拖拽排序。
- [ ] 已发布课程调整编排后触发重新校验。

## A7 音频策略

- [ ] 句子可展示真实音频、默认音频、缺失、不可访问状态。
- [ ] 使用默认音频的句子允许发布。
- [ ] 发布前展示使用默认音频的句子数量和列表。
- [ ] 默认音频未配置且缺音频时阻止发布。

## A8 发布校验

- [ ] 状态流转符合草稿、发布、下架、归档规则。
- [ ] 课程发布校验覆盖场景、句子数、排序、目标词、难度、音频。
- [ ] 批量发布可部分成功，并展示失败原因。
- [ ] 下架和归档展示学习端影响提示。

## A9 管理 API

- [ ] 管理 API 覆盖场景、课程、句子、导入、批量状态、课程编排和发布校验。
- [ ] 列表 API 支持分页、排序、关键词和完整筛选条件。
- [ ] 详情 API 返回基础字段、状态、引用信息和校验摘要。
- [ ] 所有批量 API 返回对象级失败原因。
