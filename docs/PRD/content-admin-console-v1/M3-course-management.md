# M3 course-management

## 背景 / 要解决的问题

课程必须属于场景，是学习端承载句子的直接单元。首版不固定每课句子数，需要后台允许超级管理员按课程定义句子数规则、level、解锁规则、排序和状态。

## 规则

1. 课程必须包含 `courseId`、`sceneId`、标题、slug、level、描述、排序值、句子数最小值、句子数最大值、解锁规则、状态。
2. 课程必须归属于一个场景；课程保存时 `sceneId` 不能为空。
3. 课程句子数规则为课程级配置，不使用全局固定 8-12 句。
4. 课程句子数最小值必须大于 0，最大值必须大于或等于最小值。
5. 课程状态使用 `draft`、`published`、`unpublished`、`archived`。
6. 课程发布前必须通过 M8 发布校验，包括场景状态、句子数、课程内排序、音频、目标词和难度一致性。
7. 已发布课程修改基础信息后仍保持已发布；修改句子列表或句子数规则时必须重新触发发布校验。
8. 归档课程不硬删除课程内句子关系和历史练习引用。

## 交互

- 超级管理员按场景查看课程列表 -> 查看课程状态、句子数量、句子数规则、发布校验结果。
- 超级管理员新建课程 -> 选择场景 -> 填写标题、level、描述、句子数规则、解锁规则 -> 保存为草稿。
- 超级管理员编辑课程 -> 保存后展示是否需要重新发布校验。
- 超级管理员复制课程基础信息 -> 系统生成草稿课程，不复制练习记录。
- 超级管理员归档课程 -> 系统提示学习端影响和历史引用。

## 视觉 / UI 布局

- 课程管理以场景为主筛选，左侧或顶部提供场景切换。
- 课程列表展示标题、level、句子数量、规则范围、状态、发布校验摘要。
- 课程详情分区展示基础信息、解锁规则、句子数规则、课程句子入口。

## 边界行为

- 所属场景为草稿、下架或归档时，课程不可发布。
- 课程 slug 在同一场景内必须唯一。
- 已归档课程不可直接发布，需先恢复为草稿。
- 课程句子数量超出课程级规则时，发布被阻止。

## 验收 checklist

- [ ] 可按场景新建、编辑、发布、下架、归档、恢复草稿课程。
- [ ] 课程必须绑定一个场景。
- [ ] 课程可配置句子数最小值和最大值。
- [ ] 课程列表展示实际句子数量和句子数规则。
- [ ] 场景未发布时课程不可发布。
- [ ] 修改句子列表或句子数规则后会重新触发发布校验。

## 非目标

- 不做课程封面图生成。
- 不做课程商业化配置。
- 不做用户个性化课程推荐。
