# M4 sentence-pool-management

## 背景 / 要解决的问题

已导入的大量句子需要作为句子池管理。超级管理员需要按 targetWord、sceneTag、课程分配状态、音频状态、难度、关键词等条件筛选句子，并查看句子详情、编辑字段、归档和追踪引用。

## 规则

1. 句子必须包含 `sentenceId`、英文文本、难度、目标词、短语块、场景标签、`sceneId`、`courseId`、`sortOrder`、音频字段、状态、更新时间。
2. `sceneId`、`courseId`、`sortOrder` 可为空；为空时句子属于未编排句子池。
3. 句子状态使用 `draft`、`published`、`unpublished`、`archived`。
4. 句子筛选必须支持：关键词、targetWord、sceneTag、难度、状态、是否已分配课程、是否有音频、是否使用默认音频、课程、场景。
5. 句子详情必须展示基础字段、课程归属、音频状态、目标词、短语块、引用信息、最近操作记录摘要。
6. 已被练习记录引用的句子不得硬删除，只能下架或归档。
7. 句子文本修改后，必须提示可能影响目标词、短语块、音频和练习记录解释。
8. 批量编辑目标词、sceneTag、状态、课程归属时必须展示影响数量和失败原因。

## 交互

- 超级管理员进入句子池 -> 使用筛选条件定位句子 -> 查看列表字段和批量操作入口。
- 超级管理员打开句子详情 -> 查看归属、音频、目标词、引用 -> 编辑并保存。
- 超级管理员选择未分配句子 -> 批量分配场景或课程 -> 系统展示处理结果。
- 超级管理员归档句子 -> 系统检查是否被课程或练习记录引用 -> 展示确认。

## 视觉 / UI 布局

- 句子池列表采用高密度表格，句子文本列支持多行截断和悬浮完整展示。
- 筛选区支持折叠，高频筛选常驻：关键词、课程分配状态、音频状态、状态。
- 句子详情可使用抽屉，便于从列表快速查看和返回。

## 边界行为

- 无音频句子可保存为草稿，但发布校验需依赖 M7 兜底策略。
- 句子被多个历史对象引用时，引用信息必须展示数量和类型。
- 批量分配课程时，如果目标课程已达到句子数最大值，可允许保存但标记发布校验失败；是否阻止由 M8 规则决定。
- 已归档句子默认不出现在课程编排候选池。

## 验收 checklist

- [ ] 句子池支持完整筛选条件：targetWord、sceneTag、课程分配状态、音频状态、难度、关键词等。
- [ ] 句子详情展示基础字段、归属、音频、标注和引用信息。
- [ ] 句子可编辑、下架、归档、恢复草稿。
- [ ] 已被练习引用的句子不可硬删除。
- [ ] 批量操作展示成功、失败、跳过数量。
- [ ] 已归档句子默认不进入课程编排候选池。

## 非目标

- 不做在线语法纠错。
- 不做自动标注质量评分。
- 不做硬删除历史内容。
