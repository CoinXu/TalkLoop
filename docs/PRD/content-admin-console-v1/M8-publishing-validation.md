# M8 publishing-validation

## 背景 / 要解决的问题

场景、课程和句子需要统一状态流转和发布校验。首版不做审核流，但必须避免未编排、缺关键字段或不可学习的内容进入学习端。

## 规则

1. 内容状态统一为 `draft`、`published`、`unpublished`、`archived`。
2. 状态流转允许：草稿 -> 发布、发布 -> 下架、下架 -> 发布、草稿/下架 -> 归档、归档 -> 草稿。
3. 归档对象不可直接发布，必须先恢复草稿。
4. 课程发布校验必须覆盖：所属场景已发布、句子数量符合课程规则、课程内排序完整、句子未归档、目标词非空、难度一致性、音频或默认音频可用。
5. 场景发布校验必须覆盖：至少存在 1 个可发布课程。
6. 句子单独发布校验必须覆盖：文本、目标词、难度、音频或默认音频可用。
7. 批量发布时，逐项执行校验；可发布项允许发布，不可发布项跳过并展示原因。
8. 下架或归档已发布内容时，必须提示学习端可见性影响和历史引用保留。
9. 发布校验结果分为阻断项和提示项；默认音频兜底属于提示项，默认音频未配置且缺音频属于阻断项。

## 交互

- 超级管理员点击发布课程 -> 系统展示校验结果 -> 无阻断项时可确认发布。
- 超级管理员批量发布句子或课程 -> 系统执行逐项校验 -> 展示成功、失败、跳过和失败原因。
- 超级管理员下架内容 -> 系统提示影响范围 -> 确认后下架。
- 超级管理员归档内容 -> 系统提示历史引用和恢复方式 -> 确认后归档。

## 视觉 / UI 布局

- 发布校验页按对象类型分组：场景、课程、句子。
- 校验结果分为红色阻断项和黄色提示项，文字必须说明原因和修复入口。
- 课程详情顶部展示发布状态和最近一次校验结果摘要。

## 边界行为

- 批量发布中部分失败时，不回滚成功项。
- 已发布课程的场景被下架后，学习端不展示该课程，但课程自身状态仍保留。
- 归档课程不改变其下句子状态。
- 句子被下架后，课程发布校验需标记该课程不可发布。

## 验收 checklist

- [ ] 状态流转符合草稿、发布、下架、归档规则。
- [ ] 课程发布校验覆盖场景、句子数、排序、目标词、难度、音频。
- [ ] 默认音频兜底作为提示项展示，不阻止发布。
- [ ] 默认音频未配置且缺音频时阻止发布。
- [ ] 批量发布可部分成功，并展示失败原因。
- [ ] 下架和归档展示学习端影响提示。

## 非目标

- 不做审核流。
- 不做发布定时任务。
- 不做内容版本回滚。
