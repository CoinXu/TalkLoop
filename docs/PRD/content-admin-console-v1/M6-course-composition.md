# M6 course-composition

## 背景 / 要解决的问题

课程化的关键是把句子池中的句子分配到课程，并确定课程内顺序。当前大量句子 `sceneId`、`courseId` 为空，需要后台提供左侧句子池、右侧课程句子列表的编排界面。

## 规则

1. 句子加入课程时必须同时写入 `sceneId = course.sceneId`、`courseId = selectedCourseId`、`sortOrder = 课程内顺序`。
2. 同一课程内 `sortOrder` 必须唯一。
3. 课程编排支持添加句子、移除句子、拖拽排序、批量添加、批量移除。
4. 从课程移除句子时，句子的 `courseId` 和 `sortOrder` 清空；`sceneId` 是否清空由超级管理员选择，默认保留场景归属。
5. 已发布课程调整句子列表或排序后，课程进入“需重新校验”状态。
6. 已归档句子不得加入课程。
7. 课程句子数量可以低于或高于课程规则范围保存，但发布时由 M8 阻止。
8. 批量分配课程时必须展示目标课程、待处理句子数、排序策略和冲突处理方式。

## 交互

- 超级管理员进入课程详情 -> 打开课程编排 -> 左侧筛选句子池，右侧显示课程句子列表。
- 超级管理员从左侧选择句子 -> 添加到右侧 -> 系统追加到末尾并生成 `sortOrder`。
- 超级管理员拖拽右侧句子 -> 系统更新课程内顺序。
- 超级管理员移除课程句子 -> 系统确认是否保留 `sceneId`。
- 超级管理员保存编排 -> 系统展示句子数、音频、目标词和难度的校验摘要。

## 视觉 / UI 布局

- 编排页使用左右双栏：左侧句子池筛选和候选列表，右侧课程句子列表和排序。
- 右侧课程句子列表展示序号、句子文本、难度、目标词、音频状态、发布校验标记。
- 顶部固定展示课程名称、所属场景、句子数规则、当前句子数和保存按钮。

## 边界行为

- 添加重复句子到同一课程时阻止并提示。
- 拖拽排序失败时恢复原顺序并提示。
- 多人同时编辑同一课程时，保存冲突需提示刷新后重试；具体并发策略由 @be-dev 确认。
- 批量添加后超出句子数最大值时允许保存，但发布校验失败。

## 验收 checklist

- [ ] 课程编排页具备左侧句子池和右侧课程句子列表。
- [ ] 添加句子时同步写入 `sceneId`、`courseId`、`sortOrder`。
- [ ] 支持移除句子和拖拽排序。
- [ ] 同课排序唯一，重复句子不可加入同一课程。
- [ ] 已发布课程调整编排后触发重新校验。
- [ ] 保存后展示课程发布校验摘要。

## 非目标

- 不做 AI 自动编排课程。
- 不做跨课程同步编辑。
- 不做课程版本对比。

- 下游：M8 使用课程内句子列表执行发布校验；M9 汇总课程编排 API。
