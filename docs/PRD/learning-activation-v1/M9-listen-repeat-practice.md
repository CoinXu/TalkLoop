# M9 listen-repeat-practice

## 背景 / 要解决的问题

听读功能训练用户从“听原音”到“自己说出”。以单句为最小单位，提供看读、听读、盲读三种模式，以及录音、回放、文本匹配、波形和语速反馈。

## 规则

1. 单句练习流程：播放原音 -> 用户跟读录音 -> 系统反馈 -> 重练或下一句。
2. 模式 A 看读：显示文本和原音。
3. 模式 B 听读：默认隐藏文本，可临时查看原文，3 秒后自动隐藏。
4. 模式 C 盲读：原音只能播放一次，播放后自动进入录音。
5. 用户可在任意时刻切换模式，切换不重置本句练习记录。
6. 录音时长上限为原音时长 × 3。
7. 对比播放支持原音、我的录音、连续对比。
8. 文本匹配三档：准确、部分匹配、偏差较大；60% 为部分匹配下限。
9. 波形上下排列显示，波形不自动评分。
10. 语速比按用户录音时长 / 原音时长计算，0.85x-1.15x 为正常。
11. 超过 12 词的长句支持意群练习，每个意群可独立播放和跟读。

## 交互

- 用户进入课程句子 -> 选择或默认进入练习模式。
- 用户点击录音 -> 开始录音，再次点击停止。
- 录音结束 -> 展示文本匹配、波形、语速和差异词。
- 用户选择重练 -> 保留历史记录并新增一次练习。
- 管理员进入听读练习后台 -> 查看句子练习效果、ASR 失败、音频异常和用户反馈。

## 视觉 / UI 布局

- 练习页中心展示文本或隐藏提示，下方为音频/录音控制和反馈。
- 三模式用分段控件展示。
- 反馈页展示原句、用户转写、差异词、语速和操作按钮。
- 后台听读监控页按课程、句子、准确率、ASR 失败率、音频状态筛选。

## 边界行为

- 浏览器或设备不支持录音时，提示不可用并不生成失败练习。
- ASR 失败时展示“无法识别”，允许重录。
- 模式 C 播放后刷新页面，不保留再次播放资格，需重新开始该句。
- 意群断句缺失时，长句只允许整句练习并记录内容异常。

## 验收 checklist

- [ ] 同一句支持 A 看读、B 听读、C 盲读三种模式。
- [ ] 录音、停止、回放和连续对比可用。
- [ ] 文本匹配可按准确、部分匹配、偏差较大三档展示。
- [ ] 波形对比和时长/语速对比可展示。
- [ ] 长句可按意群分段练习。
- [ ] 跟读结果可回传文本匹配率和目标词命中结果给 M7。
- [ ] 后台可查看听读练习质量、ASR 失败、音频异常和句子薄弱排行。

## 非目标

- 不做音素级评分。
- 不做节奏/重音自动评分。

## 管理后台功能

后台必须提供听读练习监控、句子质量统计、ASR 失败列表、音频异常、用户练习记录、薄弱句排行和审计。
