# M4 auto-annotation-pipeline

## 背景 / 要解决的问题

人工标注 6000+ 词和 250-300 句成本高。v1.0 需要自动生成听力陷阱、干扰项、目标词和意群断句，并由后台抽检修正。

实现级产品说明见 `auto-annotation-product-spec.md`。后端和前端拆任务时，以本文定义模块边界，以专项说明定义任务流程、后台页面和验收细节。

## 规则

1. 自动标注流程包括：导入 SUBTLEXus、专有名词过滤、偏门词过滤、词形还原、超高频词排除、难度分级、听力陷阱标注、干扰项生成、场景标签、TTS、人工抽检。
2. 音素转写优先使用 CMU Pronouncing Dictionary，未收录词使用 g2p 兜底。
3. 听力陷阱定义：用户在真实听力中容易把目标词漏听、听成其他词、听不出弱化形式，或因语流变化无法把声音映射回词条的高风险点。
4. 听力陷阱不是单纯“生词难度”，必须同时满足至少一个声音风险条件和一个学习价值条件。声音风险条件包括发音近似、弱读、连读、缩读、重音变化、吞音、语境中边界不清；学习价值条件包括词频在激活主词库内、出现在课程句中、用户词库待激活或历史错误率高。
5. 词条级近音混淆使用归一化音素编辑距离，初始阈值 `<0.45`；距离计算基于音素序列，不基于英文拼写编辑距离。
6. 英文拼写编辑距离只作为同根混淆和候选解释辅助，不得单独判定近音陷阱。
7. 连读、缩读、弱读、功能词吞音使用规则模板 + 词性/位置约束标注，不能只靠词级音素距离。
8. 同根混淆使用词元/词干相似度 + 音素距离联合判定。
9. 干扰项按发音相近、含义相近、难度相近三类预生成。
10. 句子目标词自动标注优先级：听力陷阱词 > Level 2+ > Level 1；每句最多 3 个 `target_words`。
11. 总词数超过 12 的句子自动意群断句，优先按标点和从句引导词切分。
12. 自动标注结果必须经过 10%-20% 人工抽检，审核状态至少包括 `pending_review`、`approved`、`rejected`。
13. 听力陷阱标注必须区分词条级陷阱和句子级陷阱：词条级描述该词本身易混点，句子级描述该词在当前语音上下文中的连读、弱读、吞音或重音问题。
14. 句子级陷阱必须绑定 `sentenceId`、`wordId`、`trapType`、音频片段时间范围、解释文案和置信度。
15. 已审核通过的听力陷阱可进入 M7/M9 练习提示、M8 任务优先级和 M10 薄弱项统计。
16. 每个自动生成的听力陷阱必须输出 `confidence` 和 `severity`。`confidence` 表示算法判断可靠度，`severity` 表示对学习者听错的影响程度。
17. `confidence >= 0.80` 可进入自动通过候选；`0.50-0.79` 进入人工抽检优先队列；`<0.50` 默认不进入学习端，只保留后台候选。
18. `severity` 由词频、陷阱类型、混淆词数量、课程出现次数、目标词身份和用户历史错误率共同决定。

## 听力陷阱算法口径

### A1 近音混淆

- 输入：目标词音素序列、候选词音素序列、词频等级、词性、释义。
- 候选范围：同一或相邻难度 Level、已发布词条、非超高频功能词，优先同词性或同场景。
- 算法：计算归一化音素编辑距离 `phonemeDistance = editDistance(phonemesA, phonemesB) / max(lenA, lenB)`。
- 初始判定：`phonemeDistance < 0.45` 生成近音混淆候选；`<0.30` 为高相似。
- 加权：首音相同、尾音相同、重音位置相近、元音核相近会提高置信度；词义差异过大不会取消近音候选，但会降低作为释义干扰项的优先级。
- 输出：`trapType=near_sound_confusion`、混淆词列表、音素差异说明、置信度。

### A2 弱读

- 输入：词性、是否功能词、句中位置、相邻词、常见弱读规则。
- 候选范围：冠词、介词、助动词、代词、连词、高频功能词，以及在句中非重读位置出现的常见内容词。
- 算法：规则模板匹配，例如 `to -> /tə/`、`of -> /əv/ 或 /ə/`、`and -> /ən/`、`can -> /kən/`。
- 判定：词条命中弱读规则且在句子中处于非重读位置时，生成句子级弱读陷阱。
- 输出：`trapType=weak_form`、原始强读、弱读形式、句中触发位置、解释文案。

### A3 连读

- 输入：句子 token、相邻词边界、音素序列。
- 候选范围：相邻词边界出现辅音 + 元音、相同/相近辅音、爆破音 + 辅音等组合。
- 算法：基于边界规则生成候选，例如 `pick it`、`turn on`、`want to`；需要绑定句子级目标词和音频片段。
- 判定：目标词处在连读边界且该边界会改变用户感知的词边界时，生成句子级连读陷阱。
- 输出：`trapType=linking`、涉及词组、边界类型、音频片段范围。

### A4 缩读

- 输入：标准词组、缩读词典、课程句文本。
- 候选范围：常见缩读和口语化形式，例如 `I'm`、`you're`、`don't`、`gonna`、`wanna`、`gotta`。
- 算法：词典匹配 + 词组还原；缩读形式和还原形式都要可被句子显示和反馈引用。
- 输出：`trapType=contraction`、表面形式、还原形式、解释文案。

### A5 同根混淆

- 输入：词元、词干、前后缀、音素序列、词性。
- 候选范围：同词根或共享高比例前缀/后缀的词，例如 `effect/affect`、`economic/economical`。
- 算法：词干相似度达到阈值且音素距离低于近音宽松阈值时生成候选。
- 初始判定：词干相似 + `phonemeDistance <0.60`，并且释义或词性容易造成理解混淆。
- 输出：`trapType=related_form_confusion`、同根词、差异解释。

### A6 重音位置变化

- 输入：CMU 重音标记、词性、词形。
- 候选范围：名词/动词重音不同、派生词重音移动、长词中非首重音。
- 算法：比较同词族或同形异类词的重音位置；重音位置变化影响识别时生成候选。
- 输出：`trapType=stress_shift`、重音位置、示例词族。

### A7 功能词吞音

- 输入：功能词列表、句中位置、相邻词、语速。
- 候选范围：`a/an/the/of/to/for/and/or/but` 等。
- 算法：功能词在非重读位置且相邻词形成快速语流时生成候选；若无真实音频对齐，首版按文本规则标注，置信度较低。
- 输出：`trapType=function_word_reduction`、功能词、句中位置、解释文案。

## 交互

- 内容构建阶段运行自动标注 -> 生成词条标注、句子标注和音频任务。
- 管理员进入标注任务 -> 查看算法结果、置信度、异常项。
- 管理员审核标注 -> 批准、驳回或人工修正。
- 管理员审核听力陷阱 -> 可修正类型、解释、混淆词、例句和句子音频片段范围。
- 管理员批量重跑标注 -> 系统保留历史版本和变更摘要。

## 视觉 / UI 布局

- 后台标注审核页采用左右对照：左侧原词/原句，右侧算法标注和人工修正。
- 标注结果按听力陷阱、干扰项、目标词、意群断句、音频任务分组。
- 听力陷阱审核页展示“词条级陷阱”和“句子级陷阱”两个分区。
- 低置信度和发布阻断项优先显示。

## 边界行为

- 标注失败的词或句子不得进入正式练习。
- 人工驳回后，内容保持不可发布，直到修正并通过。
- 词条级陷阱缺失不阻止词条发布；句子级陷阱缺失不阻止课程发布，但该内容不得使用陷阱专项提示。
- 句子级陷阱没有音频片段范围时，可以进入普通错题反馈，但不能进入精听定位提示。
- 重跑标注不得覆盖已人工确认的字段，除非管理员明确选择覆盖。
- 部分批量审核成功时，不回滚成功项，但必须展示逐项结果。

## 验收 checklist

- [ ] 可自动标注近音混淆、弱读、连读缩读、同根混淆。
- [ ] 近音混淆使用音素序列编辑距离，不使用英文拼写编辑距离单独判定。
- [ ] 弱读、连读、缩读、功能词吞音使用规则模板和句中位置约束判定。
- [ ] 自动生成的听力陷阱输出置信度和严重度，并按阈值进入学习端或人工复核。
- [ ] 听力陷阱区分词条级和句子级标注。
- [ ] 句子级陷阱可绑定词、句子、陷阱类型、音频片段范围和解释。
- [ ] 可为每个词预生成三类干扰项。
- [ ] 可为句子自动标注 `target_words` 和 `bonus_words`。
- [ ] 可为长句自动标注 `phrase_chunks`。
- [ ] 自动标注结果必须有审核状态。
- [ ] 后台可审核、驳回、修正和批量重跑标注。
- [ ] 未审核通过的标注不得进入正式练习。

## 非目标

- 不做实时在线标注。
- 不做用户侧标注纠错入口。

## 管理后台功能

后台必须提供标注任务列表、抽检队列、人工修正、批量审核、重跑标注、版本记录、发布阻断提示和审计。
