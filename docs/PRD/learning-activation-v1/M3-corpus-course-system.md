# M3 corpus-course-system

## 背景 / 要解决的问题

听读和单词激活需要自然、口语化、可分级的句子语料和课程结构。语料层引用词表层，并输出句子、课程、常速/慢速音频。

## 规则

1. 句子生产流程：确定场景和课程主题 -> 选取 15-20 个核心词 -> 编写 8-12 个句子 -> 审核 -> 自动标注意群和目标词 -> TTS 常速/慢速音频 -> 入库。
2. 句子难度分为 1-4 级，v1.0 以 1-3 级为主，4 级仅高级课程少量出现。
3. 每句标注 1-3 个 `target_words`，可有 `bonus_words`。
4. v1.0 课程规模为 30 课、约 250-300 句，覆盖日常生活、职场沟通、旅行英语、社交寒暄、连读专项、弱读专项、语调专项。
5. 每课 8-12 句，同一课程内难度一致，句子按难度递进。
6. 音频格式为 MP3、128kbps、44.1kHz，常速 140-160 wpm，慢速 100-120 wpm，统一到 -16 LUFS。
7. v1.0 统一使用一个 TTS 音色。
8. 缺少常速或慢速音频的句子不得发布到课程。

## 交互

- 学习端按场景 -> 课程 -> 句子展示。
- 用户进入课程 -> 查看句数、练习状态、解锁状态。
- 管理员进入句库 -> 创建、编辑、归档句子，维护目标词、bonus 词、难度、课程归属、音频。
- 管理员进入课程管理 -> 维护场景、课程标题、描述、排序、解锁条件、句子列表和发布状态。

## 视觉 / UI 布局

- 学习端课程列表按场景分组，课程项展示句数、进度、锁定原因。
- 后台句库列表支持按课程、场景、难度、目标词、音频状态、发布状态筛选。
- 后台课程详情展示课程信息、句子排序、音频完整性和发布校验。

## 边界行为

- 课程句子少于 8 句或超过 12 句时，发布前必须提示。
- 同课句子难度跨度过大时，发布前必须警告。
- 已被练习记录引用的句子和课程不得硬删除。
- TTS 生成失败时，课程保持不可发布状态。

## 验收 checklist

- [ ] 句库字段覆盖文本、音频、目标词、bonus 词、难度、场景、课程、意群和排序。
- [ ] v1.0 可配置 30 课、约 250-300 句语料。
- [ ] 课程按场景 -> 课程 -> 句子组织。
- [ ] 课程发布前校验句数、音频、目标词和难度一致性。
- [ ] 后台可管理句库、课程、音频和发布状态。
- [ ] 后台可查看句子和课程被练习记录引用的情况。
- [ ] 课程内容变更进入审计日志。

## 非目标

- 不做用户自定义课程。
- 不做多音色选择。

## 管理后台功能

后台必须提供句库管理、课程管理、音频任务管理、发布校验、批量排序、引用追踪和审计。

## 依赖

- 上游：M1 后台基础；M2 词表、场景标签和词条音频。
- 下游：M4 自动标注，M7/M9 练习，M10 报告。
