# Learning Activation v1.0 总验收清单

## M1 admin-foundation

- [ ] 首个超级管理员可通过部署期初始化创建，且无公开注册入口。
- [ ] 超级管理员可创建、启用、禁用、重置后台管理员账号。
- [ ] 系统阻止禁用、删除或降权最后一个启用超级管理员。
- [ ] 后台导航覆盖 v1.0 所有业务模块和审计日志。
- [ ] 所有后台写操作基于 `permissionKey` 校验。
- [ ] 所有敏感写操作进入审计日志。
- [ ] 业务模块复用统一列表、详情、筛选、确认和反馈规则。

## M2 word-library-system

- [ ] 词表可从 SUBTLEXus 字段构建并保留词频、上下文多样性。
- [ ] 词表过滤规则覆盖专有名词、偏门词、超高频功能词。
- [ ] 词表按 `Lg10WF` 分为 4 个难度等级。
- [ ] 词条字段覆盖释义、音频、标签、陷阱、干扰项和搭配。
- [ ] 学习端只消费已发布且字段完整的词条。
- [ ] 后台可搜索、筛选、编辑、归档和发布词条。
- [ ] 后台可查看词条引用用户词库、句子和练习记录的情况。

## M3 corpus-course-system

- [ ] 句库字段覆盖文本、音频、目标词、bonus 词、难度、场景、课程、意群和排序。
- [ ] v1.0 可配置 30 课、约 250-300 句语料。
- [ ] 课程按场景 -> 课程 -> 句子组织。
- [ ] 课程发布前校验句数、音频、目标词和难度一致性。
- [ ] 后台可管理句库、课程、音频和发布状态。
- [ ] 后台可查看句子和课程被练习记录引用的情况。
- [ ] 课程内容变更进入审计日志。

## M4 auto-annotation-pipeline

- [ ] 可自动标注近音混淆、弱读、连读缩读、同根混淆。
- [ ] 可为每个词预生成三类干扰项。
- [ ] 可为句子自动标注 `target_words` 和 `bonus_words`。
- [ ] 可为长句自动标注 `phrase_chunks`。
- [ ] 自动标注结果必须有审核状态。
- [ ] 后台可审核、驳回、修正和批量重跑标注。
- [ ] 未审核通过的标注不得进入正式练习。

## M5 level-assessment

- [ ] 首次启动必须完成 3 题自我描述。
- [ ] 自我描述前两题按矩阵生成估值，第三题只记录痛点。
- [ ] 用户可跳过验证测试并使用粗估词库。
- [ ] 验证测试可在 8-10 轮内完成。
- [ ] 验证测试按认识率自适应调整难度。
- [ ] 验证测试结果可替换粗估词库并重新生成激活计划。
- [ ] 后台可管理自我描述题、估值矩阵、验证测试采样规则和结果版本。

## M6 user-vocabulary-runtime

- [ ] 用户词库可由自我描述或验证测试结果生成。
- [ ] 用户词条记录激活状态、练习、复习、跳过和来源。
- [ ] 当前等级激活率达到 70% 可解锁下一批词。
- [ ] SRS 间隔能按状态和练习结果更新。
- [ ] 保存失败不会导致错误升级或错误完成。
- [ ] 后台可按用户查看词库状态、状态流转和异常词。
- [ ] 后台人工修正用户词库状态必须填写原因并审计。

## M7 word-activation-practice

- [ ] 三种激活状态和状态流转规则明确。
- [ ] 听音辨义支持四选一、自动播放、错词重测。
- [ ] 连续答对 2 次可从认知词升级为听觉词。
- [ ] 听句辨词可用于听觉词和活跃词复习。
- [ ] 跟读结果可驱动听觉词升级为活跃词。
- [ ] 复习失败可按规则降级。
- [ ] 后台可查看和配置练习规则、题量、重测和规则版本。

## M8 daily-task-visualization

- [ ] 每日任务包含听音辨义、跟读句子、到期复习。
- [ ] 任务数量符合规则或按词库不足展示实际数量。
- [ ] 优先级算法使用词频、陷阱、上下文多样性、复习时间和随机因子。
- [ ] Level 解锁按 70% 激活率触发。
- [ ] 首页展示三状态词数、进度和本周新激活。
- [ ] 详情页展示趋势和薄弱词 TOP 10。
- [ ] 后台可配置任务策略、查看任务生成日志和异常任务。

## M9 listen-repeat-practice

- [ ] 同一句支持 A 看读、B 听读、C 盲读三种模式。
- [ ] 录音、停止、回放和连续对比可用。
- [ ] 文本匹配可按准确、部分匹配、偏差较大三档展示。
- [ ] 波形对比和时长/语速对比可展示。
- [ ] 长句可按意群分段练习。
- [ ] 跟读结果可回传文本匹配率和目标词命中结果给 M7。
- [ ] 后台可查看听读练习质量、ASR 失败、音频异常和句子薄弱排行。

## M10 course-report-progress

- [ ] 课程按场景 -> 课程 -> 句子组织。
- [ ] 前 3 课默认解锁，后续按完成前一课解锁。
- [ ] 每课完成后展示课程报告。
- [ ] 报告包含准确度、语速、薄弱句和激活词。
- [ ] 可一键重练准确度低于 70% 的句子。
- [ ] 句子级、课程级和用户级统计可保存。
- [ ] 后台可查看课程完成率、薄弱句、用户课程进度并支持审计修正。
