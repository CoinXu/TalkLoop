# Learning Activation v1.0 总验收清单

## M1 admin-foundation

- [ ] 首个超级管理员可通过部署期初始化创建，且无公开注册入口。
- [ ] 超级管理员可创建、启用、禁用、重置后台管理员账号。
- [ ] 系统阻止禁用、删除或降权最后一个启用超级管理员。
- [ ] 后台导航覆盖 v1.0 所有业务模块和审计日志。
- [ ] 所有后台写操作基于 `permissionKey` 校验。
- [ ] 所有敏感写操作进入审计日志。
- [ ] 业务模块复用统一列表、详情、筛选、确认和反馈规则。

## M2 word-library-system

- [ ] 词表可从 SUBTLEXus 字段构建并保留词频、上下文多样性。
- [ ] 词表过滤规则覆盖专有名词、偏门词、超高频功能词。
- [ ] 词表按 `Lg10WF` 分为 4 个难度等级。
- [ ] 词条字段覆盖释义、音频、标签、陷阱、干扰项和搭配。
- [ ] 听力陷阱字段覆盖类型、解释、混淆词、例句、严重度、来源和置信度。
- [ ] 学习端可消费听力陷阱用于提示、错题反馈和复习优先级。
- [ ] 学习端只消费已发布且字段完整的词条。
- [ ] 后台可搜索、筛选、编辑、归档和发布词条。
- [ ] 后台可查看词条引用用户词库、句子和练习记录的情况。

## M3 corpus-course-system

- [ ] 句库字段覆盖文本、音频、目标词、bonus 词、难度、场景、课程、意群和排序。
- [ ] v1.0 可配置 30 课、约 250-300 句语料。
- [ ] 课程按场景 -> 课程 -> 句子组织。
- [ ] 课程发布前校验句数、音频、目标词和难度一致性。
- [ ] 后台可管理句库、课程、音频和发布状态。
- [ ] 后台可查看句子和课程被练习记录引用的情况。
- [ ] 课程内容变更进入审计日志。

## M4 auto-annotation-pipeline

- [ ] 可自动标注近音混淆、弱读、连读缩读、同根混淆。
- [ ] 近音混淆使用音素序列编辑距离，不使用英文拼写编辑距离单独判定。
- [ ] 弱读、连读、缩读、功能词吞音使用规则模板和句中位置约束判定。
- [ ] 自动生成的听力陷阱输出置信度和严重度，并按阈值进入学习端或人工复核。
- [ ] 听力陷阱区分词条级和句子级标注。
- [ ] 句子级陷阱可绑定词、句子、陷阱类型、音频片段范围和解释。
- [ ] 可为每个词预生成三类干扰项。
- [ ] 可为句子自动标注 `target_words` 和 `bonus_words`。
- [ ] 可为长句自动标注 `phrase_chunks`。
- [ ] 自动标注结果必须有审核状态。
- [ ] 后台可审核、驳回、修正和批量重跑标注。
- [ ] 未审核通过的标注不得进入正式练习。
- [ ] 后端标注任务和前端审核后台满足 `auto-annotation-product-spec.md` 的实现级要求。

## M5 level-assessment

- [ ] 首次启动必须完成基于词库词条的抽样评估。
- [ ] 评估题源只来自已发布、字段完整、未归档词条。
- [ ] 每题展示英文词、4 个中文释义和“不认识/不确定”。
- [ ] 评估按 Level 和 `Lg10WF` 词频桶自适应抽样。
- [ ] 评估可在 5-9 轮、30-54 题内完成。
- [ ] 评估结果输出词汇量估计、置信度、词频边界、已解锁层级和评估版本。
- [ ] 评估结果可生成初始用户词库和优先验证队列。
- [ ] 低置信度或题源不足时使用保守解锁策略。
- [ ] 后台可配置抽样桶、轮次、终止条件、干扰项策略和置信度阈值。

## M6 user-vocabulary-runtime

- [ ] 用户词库可由词库抽样评估结果生成。
- [ ] 用户词条记录激活状态、练习、复习、跳过和来源。
- [ ] 当前等级激活率达到 70% 可解锁下一批词。
- [ ] SRS 间隔能按状态和练习结果更新。
- [ ] 今日任务和继续学习产生的结果使用同一套状态流转和 SRS 规则。
- [ ] 高基础用户完成今日任务后，仍可继续推进已解锁词库中的可练词。
- [ ] 保存失败不会导致错误升级或错误完成。
- [ ] 后台可按用户查看词库状态、状态流转和异常词。
- [ ] 后台人工修正用户词库状态必须填写原因并审计。

## M7 word-activation-practice

- [ ] 三种激活状态和状态流转规则明确。
- [ ] 听音辨义支持四选一、自动播放、错词重测。
- [ ] 带听力陷阱的词优先进入听音辨义和听句辨词。
- [ ] 听力陷阱错题反馈展示陷阱解释和混淆点。
- [ ] 用户在每种陷阱类型上的正确率和薄弱标记可被记录。
- [ ] 连续答对 2 次可从认知词升级为听觉词。
- [ ] 听句辨词可用于听觉词和活跃词复习。
- [ ] 跟读结果可驱动听觉词升级为活跃词。
- [ ] 复习失败可按规则降级。
- [ ] 后台可查看和配置练习规则、题量、重测和规则版本。

## M8 daily-task-visualization

- [ ] 每日任务包含听音辨义、跟读句子、到期复习。
- [ ] 任务数量符合规则或按词库不足展示实际数量，且每日任务不作为用户继续学习的上限。
- [ ] 优先级算法使用词频、陷阱、上下文多样性、复习时间和随机因子。
- [ ] `trap_bonus` 只使用审核通过的听力陷阱，并能结合用户薄弱陷阱提高任务优先级。
- [ ] 详情页展示按听力陷阱类型聚合的薄弱项。
- [ ] Level 解锁按 70% 激活率触发。
- [ ] 首页展示三状态词数、进度和本周新激活。
- [ ] 详情页展示趋势和薄弱词 TOP 10。
- [ ] 完成今日任务后可继续生成更多练习批次。
- [ ] 继续学习结果能更新词库状态、SRS、激活率和报告。
- [ ] 无可练内容时展示具体原因，而不是用今日任务限制用户。
- [ ] 后台可配置任务策略、查看任务生成日志和异常任务。

## M9 listen-repeat-practice

- [ ] 同一句支持 A 看读、B 听读、C 盲读三种模式。
- [ ] 录音、停止、回放和连续对比可用。
- [ ] 文本匹配可按准确、部分匹配、偏差较大三档展示。
- [ ] 波形对比和时长/语速对比可展示。
- [ ] 长句可按意群分段练习。
- [ ] 句子级听力陷阱可在反馈页展示并支持片段重听。
- [ ] 听读练习记录用户在句子级陷阱上的表现。
- [ ] 跟读结果可回传文本匹配率和目标词命中结果给 M7。
- [ ] 后台可查看听读练习质量、ASR 失败、音频异常和句子薄弱排行。

## M10 course-report-progress

- [ ] 课程按场景 -> 课程 -> 句子组织。
- [ ] 前 3 课默认解锁，后续按完成前一课解锁。
- [ ] 每课完成后展示课程报告。
- [ ] 报告包含准确度、语速、薄弱句、薄弱听力陷阱和激活词。
- [ ] 可一键重练准确度低于 70% 的句子。
- [ ] 可按薄弱听力陷阱生成专项练习入口。
- [ ] 句子级、课程级和用户级统计可保存。
- [ ] 后台可查看课程完成率、薄弱句、薄弱陷阱、用户课程进度并支持审计修正。
