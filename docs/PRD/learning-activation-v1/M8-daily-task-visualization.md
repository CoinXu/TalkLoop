# M8 daily-task-visualization

## 背景 / 要解决的问题

用户需要每天知道练什么、练多少、进度如何。系统需要按词频、听力陷阱、上下文多样性、复习时间和随机性生成每日激活任务，并展示词汇激活进度。每日任务只代表最低推荐练习量，不能成为高基础用户继续学习的上限。

## 规则

1. 每日任务包含：认知词听音辨义、听觉词跟读句子、活跃词到期复习。
2. 默认任务量：听音辨义 6-10 个词，跟读 5-8 句，复习 3-6 个词；该数量是“今日推荐最低量”，不是每日学习上限。
3. 预计用时为 15-20 分钟。
4. 优先级公式：`l10wf_score * 0.35 + trap_bonus * 0.30 + l10cd_score * 0.20 + recency_bonus * 0.10 + random_factor * 0.05`。
5. 初始加载 Level 1 + Level 2。
6. Level 1+2 激活率达到 70% 解锁 Level 3。
7. Level 3 激活率达到 70% 解锁 Level 4。
8. 首页展示认知词、听觉词、活跃词数量、总激活进度、本周新激活。
9. 详情页展示总词库、三状态占比、本周趋势、薄弱词 TOP 10。
10. 用户完成今日任务后，系统必须提供“继续学习”入口，允许用户主动获取更多待激活、巩固中和到期复习内容。
11. 继续学习不设固定每日上限；只要用户词库中存在可练词、可用句子和可用音频，系统就可以继续生成下一批练习。
12. 继续学习的批次规模默认小于或等于今日任务单批规模，完成一批后由用户主动继续，避免一次性生成过长队列。
13. 继续学习的优先级顺序为：已到期复习的活跃词 -> 巩固中的听觉词 -> 当前解锁等级内的待激活认知词 -> 下一批已解锁词。
14. 继续学习产生的练习结果与今日任务同等更新用户词库状态、SRS、激活率和课程报告，不得作为“额外练习”丢弃。
15. 当用户连续完成多批继续学习时，系统只做疲劳提醒和阶段总结，不强制停止。
16. `trap_bonus` 只来自审核通过的词条级或句子级听力陷阱；用户在某类陷阱上连续失败时，该类陷阱相关词和句子的优先级进一步提高。
17. 每日任务中必须尽量混入至少 1 个用户薄弱听力陷阱相关练习；无可用陷阱内容时按普通任务生成。

## 交互

- 用户打开首页 -> 查看今日任务和词汇激活卡片。
- 用户点击开始练习 -> 按任务顺序进入 M7/M9 练习。
- 用户完成今日任务 -> 系统展示完成反馈、今日新增激活数、继续学习入口。
- 用户点击继续学习 -> 系统按优先级生成下一批练习 -> 用户完成后可再次继续。
- 用户点击词汇卡片 -> 进入激活详情页。
- 用户在详情页查看薄弱词 -> 可看到按听力陷阱类型聚合的薄弱项。
- 管理员进入任务策略后台 -> 查看任务生成规则、用户任务生成日志、异常任务。
- 管理员调整任务策略 -> 新任务使用新策略，历史任务保留。

## 视觉 / UI 布局

- 首页今日任务展示三段任务、预计用时、当前阶段、激活率。
- 今日任务完成态展示“继续学习”主按钮，以及“再练一组待激活词 / 巩固跟读 / 复习到期词”等入口。
- 词汇激活卡片使用三状态数字和进度条。
- 详情页薄弱词 TOP 10 下方展示薄弱陷阱类型分布，例如近音混淆、弱读、连读。
- 后台任务策略页展示参数、策略版本、生成样例和用户任务日志。

## 边界行为

- 某类可用词不足时，按实际数量展示，不伪造任务。
- 今日任务完成后，如果仍有可练内容，不能展示“今天都学完了”作为终态，只能展示“今日推荐已完成，可继续学习”。
- 继续学习无可练内容时，展示具体原因：无已解锁待激活词、无可用句子、无音频、复习未到期或内容未发布。
- 继续学习中途退出时，已完成的练习立即结算，未开始的题不计失败。
- 用户没有任何审核通过的陷阱数据时，不展示陷阱分布空图，只展示普通薄弱词。
- 当天任务保存失败时，不展示为已完成。
- 用户跨天未完成任务时，重新计算到期复习并合并未完成项。
- 管理员策略变更必须记录版本和审计。

## 验收 checklist

- [ ] 每日任务包含听音辨义、跟读句子、到期复习。
- [ ] 任务数量符合规则或按词库不足展示实际数量，且每日任务不作为用户继续学习的上限。
- [ ] 优先级算法使用词频、陷阱、上下文多样性、复习时间和随机因子。
- [ ] `trap_bonus` 只使用审核通过的听力陷阱，并能结合用户薄弱陷阱提高任务优先级。
- [ ] 详情页展示按听力陷阱类型聚合的薄弱项。
- [ ] Level 解锁按 70% 激活率触发。
- [ ] 首页展示三状态词数、进度和本周新激活。
- [ ] 详情页展示趋势和薄弱词 TOP 10。
- [ ] 完成今日任务后可继续生成更多练习批次。
- [ ] 继续学习结果能更新词库状态、SRS、激活率和报告。
- [ ] 无可练内容时展示具体原因，而不是用今日任务限制用户。
- [ ] 后台可配置任务策略、查看任务生成日志和异常任务。

## 非目标

- 不做排行榜。
- 不做社交打卡分享。
- 不做强制每日学习上限。

## 管理后台功能

后台必须提供任务策略配置、听力陷阱优先级配置、继续学习策略配置、任务生成日志、用户任务详情、异常任务重算、策略版本和审计。
