# M5 level-assessment

## 背景 / 要解决的问题

用户首次使用时需要快速建立词汇水平画像。评估必须基于系统词库里的真实词条，而不是只依赖自我描述。系统通过抽样测试用户对词库词条的识别能力，估算用户在不同词频难度层的认识率，再生成初始用户词库和激活计划。

## 规则

1. 首次启动必须完成词库抽样评估；自我描述只用于记录学习目标和听说痛点，不用于直接估算词汇量。
2. 评估题源只能来自 M2 中已发布、字段完整、未归档的词条。
3. 可进入评估题源的词条必须具备：`word_id`、`word`、中文释义、难度 Level、`Lg10WF`、`Lg10CD`，优先使用已有干扰项。
4. 评估题型为词义识别：展示英文词，用户从 4 个中文释义中选择 1 个，另提供“不认识/不确定”选项。
5. 每题 1 个正确释义 + 3 个干扰释义；干扰项优先来自同难度、相近词性、相近场景或相近含义词，避免明显错误选项。
6. 答对计为该词 `recognized`；答错或选择“不认识/不确定”计为 `unrecognized`。
7. 评估按词频难度分层抽样，使用 M2 的 Level 1-4 和 `Lg10WF` 细分桶；每轮 6 个词。
8. 首轮从 Level 2 中段抽样；如果用户选择过自我描述，可只作为首轮起点微调，不直接决定结果。
9. 每轮结束后按当前轮认识率调整下一轮难度：`>=80%` 进入更难桶，`<=40%` 进入更易桶，`41%-79%` 在当前桶和相邻桶继续精确抽样。
10. 评估最少 5 轮、最多 9 轮，即 30-54 题；连续 2 轮边界落在同一难度桶且相邻桶认识率差异稳定时可提前结束。
11. 系统必须记录每个抽样桶的题目数、答对数、认识率，并用单调平滑规则修正异常结果：更难桶认识率不得高于更易桶，除非样本量不足并标记低置信度。
12. 评估结果输出 `vocabularyEstimate`、`confidenceLevel`、`recognizedBands`、`frontierBand`、`initialUnlockedLevels`、`assessmentVersion`。
13. 初始用户词库由评估结果从 M2 词库生成：位于已认识桶及更易桶内的词进入用户词库，初始状态为认知词 `red`；未达到置信度的边界词进入优先验证队列。
14. Level 解锁起点由评估结果决定：默认解锁用户已认识边界及以下的词频层；边界不稳定时只解锁到更保守的一层。
15. 用户可在“我的”页面重新评估；重新评估后生成新评估版本，并提示是否重算未开始练习的用户词库。
16. 已有练习历史的词条不得被重新评估直接删除；只能调整后续任务优先级和未开始词条范围。
17. 后台可配置抽样桶、每轮题数、最大轮数、提前终止条件、干扰项策略和置信度阈值。

## 交互

- 用户首次启动 -> 进入词库水平评估说明页 -> 开始测试。
- 系统展示英文词和 4 个中文释义 + “不认识/不确定” -> 用户选择后进入下一题。
- 每 6 题完成一轮 -> 系统短暂展示进度，不展示对错明细，避免用户临时记忆影响后续。
- 测试完成 -> 展示描述性结果，例如“你已经能识别一批常用生活和职场词，接下来重点激活听说能力”。
- 用户点击开始激活 -> 系统根据评估结果生成用户词库和今日任务。
- 用户在“我的”页面点击重新评估 -> 系统说明可能重算未开始词条 -> 用户确认后重新测试。
- 管理员进入评估后台 -> 查看抽样桶配置、题源覆盖率、评估版本、用户评估结果和异常样本。

## 视觉 / UI 布局

- 评估页每屏只展示 1 个英文词、4 个释义选项和“不认识/不确定”。
- 选项文案必须短，避免长释义导致阅读负担大于词汇识别本身。
- 顶部只展示轻量进度，例如“第 2 组 / 最多 9 组”，不展示精确分数。
- 结果页不展示考试排名，展示初始激活计划、已解锁层级和开始练习入口。
- 后台评估配置页展示词频桶、样本量、题源覆盖率、干扰项质量和结果分布。

## 边界行为

- 某个词频桶可用词不足时，系统从相邻桶补样，并在评估结果中标记低置信度。
- 词条缺释义、缺难度、缺词频或已归档时，不得进入评估题源。
- 干扰项不足时，该词不得作为正式评估题，除非后台明确允许使用备用干扰项策略。
- 用户中断评估时，可继续当前评估；超过 24 小时未完成则重新开始，避免记忆污染。
- 用户明显随机作答时，例如极易词连续错误且极难词连续正确，结果标记低置信度，并使用保守解锁策略。
- 评估保存失败时，不生成用户词库，不进入首页任务。
- 评估配置变更不 retroactively 修改已有用户结果，除非管理员主动重算。

## 验收 checklist

- [ ] 首次启动必须完成基于词库词条的抽样评估。
- [ ] 评估题源只来自已发布、字段完整、未归档词条。
- [ ] 每题展示英文词、4 个中文释义和“不认识/不确定”。
- [ ] 评估按 Level 和 `Lg10WF` 词频桶自适应抽样。
- [ ] 评估可在 5-9 轮、30-54 题内完成。
- [ ] 评估结果输出词汇量估计、置信度、词频边界、已解锁层级和评估版本。
- [ ] 评估结果可生成初始用户词库和优先验证队列。
- [ ] 低置信度或题源不足时使用保守解锁策略。
- [ ] 后台可配置抽样桶、轮次、终止条件、干扰项策略和置信度阈值。

## 非目标

- 不做标准化考试报告。
- 不要求用户输入拼写。
- 不用自我描述直接推算词汇量。
- 不在评估中测试听力或口语发音；听说能力由后续激活练习判断。

## 管理后台功能

后台必须提供评估题源覆盖率、抽样桶配置、每轮题数、最大轮数、提前终止条件、干扰项策略、置信度阈值、评估版本管理、用户评估结果查看、重算入口和审计。

## 依赖

- 上游：M1 后台基础；M2 词频分层词表、释义、难度、干扰项和发布状态。
- 下游：M6 使用评估结果生成用户词库；M8 使用评估结果展示初始任务和解锁层级。
