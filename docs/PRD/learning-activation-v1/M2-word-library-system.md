# M2 word-library-system

## 背景 / 要解决的问题

词库是 v1.0 的数据基座。系统需要从 SUBTLEXus 构建口语化词表，完成过滤、分级、场景标签和用户词库基础字段定义。

## 规则

1. 词频数据基于 SUBTLEXus，保留 `Word`、`FREQcount`、`CDcount`、`FREQlow`、`CDlow`、`SUBTLWF`、`Lg10WF`、`SUBTLCD`、`Lg10CD`。
2. 疑似专有名词默认排除：`FREQlow / FREQcount < 0.2` 且首字母大写，常见普通名词例外。
3. `Lg10CD < 1.93` 的偏门词排除。
4. 词形还原后合并为词元，目标词表规模约 6000-7000 词元。
5. `Lg10WF >= 4.30` 的超高频功能词排除出激活主词库。
6. 难度分级：Level 1 为 `3.30-4.29`，Level 2 为 `2.30-3.29`，Level 3 为 `1.30-2.29`，Level 4 为 `<1.30`。
7. Level 1 + Level 2 是 v1.0 主要激活战场，约 2000-2500 词。
8. 每个词可有 1-3 个场景标签，至少覆盖日常生活、职场、旅行、社交。
9. 词条字段必须包含 `word_id`、`word`、音标、中文释义、英文释义、音频、词频、上下文多样性、难度、标签、听力陷阱、干扰项、词性、常见搭配。

## 交互

- 学习端不直接展示完整词库，只消费评估词、练习词、课程句、进度卡和薄弱词。
- 用户在练习中遇到词条缺音频或缺释义 -> 系统跳过该词并记录内容异常。
- 管理员进入词库管理 -> 查看、搜索、筛选、编辑、归档词条。
- 管理员打开词条详情 -> 查看词频、难度、标签、释义、音频、陷阱、干扰项和引用情况。

## 视觉 / UI 布局

- 学习端词汇展示以状态和任务为主，不做完整词典页。
- 后台词库列表采用高密度表格，支持按词、难度、场景、陷阱、音频状态、发布状态筛选。
- 词条详情分为基础信息、词频难度、场景标签、听力陷阱、干扰项、音频、引用记录。

## 边界行为

- 缺少释义或音频的词不得进入听音辨义。
- 已被用户词库或练习记录引用的词不得硬删除，只能归档或创建新版本。
- 词频字段缺失时，该词不得发布到正式词库。
- 管理员修改已发布词条关键字段时，必须提示影响已有用户记录。

## 验收 checklist

- [ ] 词表可从 SUBTLEXus 字段构建并保留词频、上下文多样性。
- [ ] 词表过滤规则覆盖专有名词、偏门词、超高频功能词。
- [ ] 词表按 `Lg10WF` 分为 4 个难度等级。
- [ ] 词条字段覆盖释义、音频、标签、陷阱、干扰项和搭配。
- [ ] 学习端只消费已发布且字段完整的词条。
- [ ] 后台可搜索、筛选、编辑、归档和发布词条。
- [ ] 后台可查看词条引用用户词库、句子和练习记录的情况。

## 非目标

- 不做用户自建词库。
- 不做外部词表导入。

## 管理后台功能

后台必须提供词库管理、批量发布/归档、音频状态检查、字段完整性校验、引用追踪、操作审计。

## 依赖

- 上游：M1 提供后台权限和审计。
- 下游：M3-M10 使用本模块的词条、难度、标签、音频和发布状态。
