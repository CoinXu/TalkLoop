# M10 course-report-progress

## 背景 / 要解决的问题

用户完成课程后需要看到练习成果、薄弱句和本课激活词。系统也需要保存句子级、课程级和用户级统计，供学习端展示和后台排障。

## 规则

1. 课程层级为场景 -> 课程 -> 句子。
2. 前 3 课默认解锁，后续课程完成前一课后解锁。
3. 用户可在已解锁课程中自由选择。
4. 每课完成后展示课程报告。
5. 课程报告包含练习句数、平均准确度、平均语速、表现最好句、需要多练句、本课激活词。
6. “重练薄弱句”自动筛选准确度低于 70% 的句子。
7. 句子级记录包含练习次数、最佳准确度、最近准确度、最近模式、最近语速、首次/最后练习时间。
8. 课程级记录包含完成度、平均准确度、练习轮次、薄弱句、是否解锁下一课。
9. 用户级统计展示累计练习句数、跟读次数、练习时长、连续打卡、准确度趋势、完成课程数、解锁场景数。

## 交互

- 用户完成课程全部句子 -> 系统展示本次课程报告。
- 用户点击重练薄弱句 -> 系统生成专项练习。
- 用户进入我的练习统计 -> 查看累计数据和趋势。
- 管理员进入课程报告后台 -> 查看课程完成率、薄弱句排行、用户课程进度。
- 管理员查看用户详情 -> 可进入该用户句子级和课程级记录。

## 视觉 / UI 布局

- 课程报告按概览、表现最好、需要多练、本课激活词展示。
- 我的练习统计展示累计指标和准确度趋势。
- 后台报告页提供课程维度、句子维度、用户维度三类视图。

## 边界行为

- 课程音频或句子缺失时，该课程不得解锁。
- 用户重复练习同一课程，报告以本次练习为主，同时更新历史最好成绩。
- 统计保存失败时，不标记课程完成。
- 管理员手动修正课程进度必须填写原因并审计。

## 验收 checklist

- [ ] 课程按场景 -> 课程 -> 句子组织。
- [ ] 前 3 课默认解锁，后续按完成前一课解锁。
- [ ] 每课完成后展示课程报告。
- [ ] 报告包含准确度、语速、薄弱句和激活词。
- [ ] 可一键重练准确度低于 70% 的句子。
- [ ] 句子级、课程级和用户级统计可保存。
- [ ] 后台可查看课程完成率、薄弱句、用户课程进度并支持审计修正。

## 非目标

- 不做付费课程解锁。
- 不做排行榜。

## 管理后台功能

后台必须提供课程进度查询、课程报告查询、薄弱句排行、用户练习统计、异常记录修正、数据导出待确认和审计。

## 依赖

- 上游：M1 后台基础；M3 课程；M7 激活结果；M8 任务结果；M9 跟读结果。
- 下游：无。
