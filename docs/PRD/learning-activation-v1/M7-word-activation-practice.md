# M7 word-activation-practice

## 背景 / 要解决的问题

单词激活把“认知词”逐步转化为“听觉词”和“活跃词”。本模块定义状态流转和三类激活练习。

## 规则

1. 单词状态只有三类：认知词 `red`、听觉词 `yellow`、活跃词 `green`。
2. 新词入库为认知词。
3. 认知词通过听音辨义连续答对 2 次升级为听觉词。
4. 听觉词通过跟读句子准确读出同一目标词 2 次升级为活跃词。
5. 活跃词复习中连续 2 次未准确读出降级为听觉词。
6. 听觉词复习听音辨义连续 3 次答错可降级为认知词。
7. 不允许认知词直接升级为活跃词。
8. 听音辨义为四选一：1 个正确释义 + 3 个干扰项。
9. 听句辨词播放完整句子不显示文本，最多重播 2 次。
10. 跟读激活结果来自 M9：文本匹配 >=90% 且目标词出现计为读出；60%-89% 且目标词出现计为读出但标记发音可能不准；<60% 不计入激活。
11. 带听力陷阱的词必须优先进入听音辨义和听句辨词，系统记录用户在每种 `trapType` 上的正确率。
12. 听音辨义的干扰项优先使用同陷阱类型的混淆词，例如近音词、同根词或弱读后易混词。
13. 用户在同一 `trapType` 连续 2 次失败时，词条标记对应陷阱薄弱项，并提高后续任务优先级。
14. 用户答错后反馈必须说明本题关联的听力陷阱，例如“这个词和 X 近音，注意 /.../ 的差别”；无审核通过陷阱时不展示陷阱解释。

## 交互

- 用户进入听音辨义 -> 自动播放单词发音 -> 四选一作答。
- 用户答错 -> 显示正确答案并加入稍后重测队列。
- 用户答错陷阱题 -> 系统展示听力陷阱解释、混淆词和可重听入口。
- 用户进入听句辨词 -> 播放句子 -> 选择听到的目标词。
- 用户完成跟读句子 -> 系统根据 M9 反馈更新目标词读出次数。
- 管理员查看激活规则 -> 可查看规则版本、练习配置和用户练习异常。

## 视觉 / UI 布局

- 听音辨义突出音频播放和四个释义选项。
- 错题反馈页在有审核通过陷阱时展示“为什么容易听错”说明。
- 听句辨词不展示句子文本，只展示词选项和重播次数。
- 后台练习配置页展示状态流转规则、题量、重测队列和规则版本。

## 边界行为

- 单词音频缺失时，不进入听音辨义。
- 干扰项不足时，不生成该题。
- 词条没有审核通过的听力陷阱时，仍可进入普通练习，但不显示陷阱解释，也不计入陷阱专项统计。
- ASR 不可用时，跟读激活不更新为活跃词，只记录练习失败原因。
- 管理员调整规则后，仅影响新练习，历史结果保留原规则版本。

## 验收 checklist

- [ ] 三种激活状态和状态流转规则明确。
- [ ] 听音辨义支持四选一、自动播放、错词重测。
- [ ] 带听力陷阱的词优先进入听音辨义和听句辨词。
- [ ] 听力陷阱错题反馈展示陷阱解释和混淆点。
- [ ] 用户在每种陷阱类型上的正确率和薄弱标记可被记录。
- [ ] 连续答对 2 次可从认知词升级为听觉词。
- [ ] 听句辨词可用于听觉词和活跃词复习。
- [ ] 跟读结果可驱动听觉词升级为活跃词。
- [ ] 复习失败可按规则降级。
- [ ] 后台可查看和配置练习规则、题量、重测和规则版本。

## 非目标

- 不做拼写输入题。
- 不做自由口语评分。

## 管理后台功能

后台必须提供练习规则配置、陷阱题优先级配置、题量配置、规则版本、练习异常监控、单用户练习记录查看和审计。
