# 词库自动标注算法产品文档

## 背景 / 要解决的问题

`docs/tmp/v0.3.md` 已定义词库自动标注算法。现有 M4 PRD 已覆盖自动标注方向，但还不足以直接指导后端和前端实现：后端需要明确输入、处理流程、产出字段、任务状态和失败处理；前端需要明确后台审核、修正、重跑和结果展示。

本文作为 M4 `auto-annotation-pipeline` 的实现级产品说明，供 @be-dev 和 @fe-dev 拆任务使用。本文不定义数据库迁移和具体路由命名，接口契约由 @be-dev / @tech-lead 细化。

## 目标

1. 后端可以基于 SUBTLEXus 和语料句子批量生成词条标注、听力陷阱、干扰项、句子目标词、意群断句和标注任务结果。
2. 前端后台可以查看自动标注结果、筛选低置信度项、人工修正、批量审核、重跑任务和查看版本历史。
3. 学习端可以消费审核通过的标注，用于听音辨义、听句辨词、听读反馈、任务优先级和课程报告。

## 上游输入

- SUBTLEXus 原始词频数据：`Word`、`FREQcount`、`CDcount`、`FREQlow`、`CDlow`、`SUBTLWF`、`Lg10WF`、`SUBTLCD`、`Lg10CD`。
- 词条补充字段：中文释义、英文释义、词性、常见搭配、场景标签、音频状态。
- 发音资源：CMU Pronouncing Dictionary；CMU 未收录词使用 g2p 兜底。
- 课程句子：英文文本、场景标签、课程归属、难度、音频。
- 规则配置：专有名词白名单、弱读词表、缩读词典、连读规则、词根规则、抽检比例、置信度阈值。

## 后端标注流程

```text
① 导入 SUBTLEXus 原始数据
  ↓
② 排除疑似专有名词
  ↓
③ 排除偏门词
  ↓
④ 词形还原 + 词元合并
  ↓
⑤ 排除超高频功能词
  ↓
⑥ 按 Lg10WF 分 4 级
  ↓
⑦ 音素转写
  ↓
⑧ 听力陷阱自动标注
  ↓
⑨ 干扰项自动生成
  ↓
⑩ 句子目标词自动标注
  ↓
⑪ 意群断句自动标注
  ↓
⑫ 标注任务入库，生成抽检队列
```

## 词表生成规则

1. 疑似专有名词排除：`FREQlow / FREQcount < 0.2` 且首字母大写；常见普通名词白名单保留。
2. 偏门词排除：`Lg10CD < 1.93`。
3. 词形还原后按词元合并：
   - `FREQcount = sum(所有词形 FREQcount)`
   - `CDcount = max(所有词形 CDcount)`
   - `SUBTLWF = FREQcount / 51000000 * 1000000`
   - `Lg10WF = log10(FREQcount + 1)`
   - `SUBTLCD = CDcount / 8388 * 100`
   - `Lg10CD = log10(CDcount + 1)`
4. 超高频功能词排除：`Lg10WF >= 4.30`。
5. 难度分级：
   - Level 1：`Lg10WF 3.30-4.29`
   - Level 2：`Lg10WF 2.30-3.29`
   - Level 3：`Lg10WF 1.30-2.29`
   - Level 4：`Lg10WF < 1.30`

## 听力陷阱算法

### 定义

听力陷阱是用户在真实听力中容易把目标词漏听、听成其他词、听不出弱化形式，或因语流变化无法把声音映射回词条的高风险点。

必须同时满足：

- 声音风险：近音、弱读、连读、缩读、重音变化、吞音、语境中边界不清。
- 学习价值：词在激活主词库内、出现在课程句中、用户词库待激活或历史错误率高。

### 近音混淆

- 输入：目标词音素序列、候选词音素序列、词频等级、词性、释义。
- 算法：`phonemeDistance = editDistance(phonemesA, phonemesB) / max(lenA, lenB)`。
- 初始阈值：`phonemeDistance < 0.45` 生成候选；`<0.30` 为高相似。
- 限制：英文拼写编辑距离不能单独判定近音陷阱，只能作为解释辅助。
- 输出：`trapType=near_sound_confusion`、`confusableWordIds`、音素差异说明、`confidence`、`severity`。

### 连读 / 缩读 / 弱读

- 连读：基于相邻词边界规则，例如辅音 + 元音、爆破音 + 辅音。
- 缩读：基于缩读词典，例如 `want to -> wanna`、`going to -> gonna`、`got to -> gotta`、`don't know -> dunno`。
- 弱读：基于弱读词表和句中非重读位置，例如 `the`、`a`、`of`、`to`、`for`、`can`、`would`、`was`。
- 输出必须区分词条级陷阱和句子级陷阱；句子级陷阱要绑定 `sentenceId`、`wordId`、`trapType`、音频片段范围、解释和置信度。

### 同根混淆

- 输入：词元、词干、前后缀、音素序列、词性。
- 判定：共享前缀/词根 + 音素距离低于阈值。
- 初始阈值：`phonemeDistance < 0.35` 标记强同根混淆；`0.35-0.60` 进入人工复核候选。
- 示例：`economic/economical`、`historic/historical`、`comprehend/comprehensive`。

### 置信度和严重度

- `confidence >= 0.80`：可进入自动通过候选。
- `0.50-0.79`：进入人工抽检优先队列。
- `<0.50`：默认不进入学习端，只保留后台候选。
- `severity` 由词频、陷阱类型、混淆词数量、课程出现次数、目标词身份和用户历史错误率共同决定。

## 干扰项生成规则

每个词预生成 3 类干扰项池：

| 类型 | 取法 | 用途 |
|---|---|---|
| phonetic | 音素编辑距离最近的词 | 听音辨义中的发音混淆 |
| semantic | 同场景标签、释义相近、难度接近的词 | 防止题目过于机械 |
| similar_level | 同 Level 或相邻 Level 的词 | 保证选项难度一致 |

出题时从 3 个池中组合 3 个干扰项，避免每次固定同一组选项。干扰项必须与正确答案难度接近，不能明显过难或过易。

## 句子目标词标注规则

1. 对句子分词并词形还原。
2. 匹配 M2 词表。
3. 按优先级标注：
   - 优先级 1：听力陷阱词 -> `target_words`
   - 优先级 2：Level 2+ -> `target_words`
   - 优先级 3：Level 1 -> `target_words` 或 `bonus_words`
4. 每句最多 3 个 `target_words`；多余词降为 `bonus_words`。
5. 目标词必须回写 `wordId`，不能只保存字符串。

## 意群断句规则

1. 句子不超过 12 个词时默认不切分。
2. 超过 12 个词时按以下优先级切分：
   - 标点：逗号、分号、破折号。
   - 从句引导词：`that/which/who/where/when/if/because/although/since/while`。
   - 并列连接词：`but/and`，仅在切分后片段仍自然时使用。
3. 每个意群必须保留原文顺序和起止 token 位置。
4. 意群断句是辅助练习字段，不改变句子原文。

## 标注任务状态

| 状态 | 含义 |
|---|---|
| queued | 等待执行 |
| running | 正在执行 |
| completed | 执行完成 |
| partial_failed | 部分项目失败 |
| failed | 整体失败 |
| reviewed | 人工复核完成 |

每次任务必须记录任务类型、输入范围、规则版本、开始时间、结束时间、成功数、失败数、低置信度数、操作者或触发来源。

## 标注结果状态

| 状态 | 含义 |
|---|---|
| auto_approved | 高置信度自动通过候选 |
| pending_review | 待人工复核 |
| approved | 人工确认通过 |
| rejected | 人工驳回 |
| edited | 人工修正后通过 |

学习端只消费 `auto_approved`、`approved`、`edited`，不得消费 `pending_review` 和 `rejected`。

## 后端能力要求

后端至少提供以下能力，具体路由由 @be-dev / @tech-lead 设计：

- 启动词表自动标注任务。
- 启动句子自动标注任务。
- 查询任务列表、任务详情、任务进度和失败原因。
- 查询标注结果列表，支持按类型、状态、置信度、严重度、词、句子、课程筛选。
- 单条修正标注结果。
- 批量审核、批量驳回、批量重跑。
- 查看规则版本和本次任务使用的配置快照。
- 导出低置信度或失败项，供人工处理。

后端必须保证：重跑任务不得覆盖已人工确认字段，除非请求明确选择覆盖人工结果。

## 前端后台要求

### 标注任务列表

- 展示任务类型、状态、输入范围、规则版本、成功数、失败数、低置信度数、开始/结束时间。
- 支持按任务类型、状态、时间筛选。
- 提供查看详情、重跑、导出失败项入口。

### 标注结果审核页

- 按类型分组：听力陷阱、干扰项、目标词、意群断句。
- 支持筛选：状态、置信度、严重度、词、句子、课程、陷阱类型。
- 展示算法建议、置信度、严重度、解释、原始词/句、人工修正区域。
- 支持批准、驳回、编辑后通过、批量处理。

### 听力陷阱审核视图

- 词条级陷阱：展示目标词、音标、混淆词、音素距离、陷阱类型、解释、置信度。
- 句子级陷阱：展示句子文本、目标词、陷阱类型、音频片段范围、解释、置信度。
- 有音频片段时支持播放片段；无片段时展示“仅解释，不支持片段重听”。

### 句子目标词和意群审核视图

- 句子目标词以 token 高亮展示，区分 `target_words` 和 `bonus_words`。
- 意群断句以分段形式展示，支持调整切分点。
- 保存后记录人工修正摘要。

## 边界行为

- CMU 和 g2p 都无法得到音素时，该词不参与近音混淆，但可参与语义/难度干扰项。
- 干扰项不足 3 个时，该词不得进入听音辨义正式题库。
- 句子找不到任何目标词时，标记内容异常，不阻止句子保存，但不得发布到正式练习。
- 意群断句低置信度时，句子仍可整句练习，但不进入意群练习。
- 自动标注失败不得影响已发布内容，直到新标注通过并被发布流程采纳。
