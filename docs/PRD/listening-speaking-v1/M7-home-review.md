# M7 home-review

## 背景 / 要解决的问题

H5 验证版需要一个直接的学习入口和复习入口，让用户能继续未完成单元、查看已完成单元、基于评分记录重复练习。首页不承担营销页职责。

## 规则

1. 首页必须展示已发布且用户可访问的学习单元列表。
2. 登录用户首页必须展示继续学习入口，来源为 M2 的最新 `unitProgress`。
3. 单元卡片必须展示标题、目标表达、中文释义、预计时长、完成状态、最近评分。
4. 已完成单元必须提供复习入口，进入后优先跳到跟读或替换说步骤，而不是从头听完整单元。
5. 未完成单元点击后回到 M5 保存的当前步骤。
6. 首页不得展示排行榜、社区动态、营销 banner。
7. 普通用户不得看到 `licenseStatus=internal_review`、`restricted`、`rejected`、`unknown` 或未发布单元。
8. 内部测试账号可看到 `publishStatus=published` 且 `licenseStatus=internal_review` 的单元，并应有内部测试标识。

## 交互

- 用户打开 H5 -> 首页展示继续学习和单元列表。
- 用户点击未开始单元 -> 进入 M5 的目标表达页。
- 用户点击进行中单元 -> 进入 M5 保存步骤。
- 用户点击已完成单元的“再练一次” -> 进入 M5 的跟读或替换说。
- 用户点击评分历史 -> 查看该单元最近评分列表，并可选择某一句再练。

## 视觉 / UI 布局

- 首页首屏优先展示“继续学习”，其次是单元列表。
- 单元卡片紧凑，适合移动端浏览。
- 评分用数字和简短状态展示，不做复杂图表。
- 复习入口使用明确按钮，如“再说一次”。

## 边界行为

- 无学习记录时，首页不展示空的继续学习区，直接展示推荐第一个单元。
- 无已完成单元时，复习区隐藏。
- 评分记录加载失败时，不影响单元列表展示。
- 用户未登录时，首页展示公开单元，但不展示个人继续学习。
- 用户非内部测试账号时，首页不得展示内部审核单元。

## 验收 checklist

- [ ] 首页能展示可学习单元列表。
- [ ] 登录用户能看到继续学习入口。
- [ ] 未完成单元能回到上次学习步骤。
- [ ] 已完成单元能快速进入再练习。
- [ ] 首页不出现社区、营销和排行榜功能。
- [ ] 普通用户看不到 `internal_review` 单元，内部测试账号可看到并带内部测试标识。

## 非目标

- 不做落地页和品牌营销页。
- 不做课程分类市场。
- 不做复杂数据报表。

## 依赖

- 上游：M1 的已发布单元字段和 `licenseStatus`；M2 的 `unitProgress`、`scoreHistory` 和 `isInternalTester`; M6 的最近评分记录。
- 下游：无。

- 2026-05-02：明确普通用户不可见 `internal_review` 单元，内部测试账号可见并带标识。原因：修复 M1/M7 对授权可见性的表述缺口；见 conflicts.md/C3。
