# Listening Speaking V1 总验收清单

## A. 内容与授权

- [ ] A1. 后台可创建一个包含目标表达、音频、文字稿、目标句、替换说练习的学习单元。
- [ ] A2. 单元记录 `sourceType`、`sourceUrl`、`licenseStatus` 和 `publishStatus`。
- [ ] A3. BBC URL 导入只生成草稿或内部审核内容，不自动授权通过。
- [ ] A4. 授权不可用或未发布的单元不会出现在普通用户学习列表。
- [ ] A5. 发布前系统阻止缺少音频、文字稿、目标句、替换说练习的单元。
- [ ] A6. `licenseStatus=unknown` 或 `rejected` 的单元不能发布。
- [ ] A7. `licenseStatus=internal_review` 的已发布单元仅内部测试账号可见，普通用户不可见。

## B. 音频文字稿同步

- [ ] B1. 系统可基于音频和文字稿生成句段级同步时间轴。
- [ ] B2. 运营可人工调整每段开始和结束时间。
- [ ] B3. 播放音频时，H5 学习端可高亮当前文字段。
- [ ] B4. 目标跟读句的 `segmentId` 可定位到对应示范音频片段。
- [ ] B5. 未同步单元不能进入完整学习流程。

## C. 账号与进度

- [ ] C1. 用户可登录并保存学习数据。
- [ ] C2. 系统按 `userId` 和 `unitId` 保存学习步骤。
- [ ] C3. 用户退出后再次进入同一单元，可继续上次步骤。
- [ ] C4. 单元完成状态能被首页读取。
- [ ] C5. 同一评分对象的多次评分记录不会互相覆盖。

## D. 学习主流程

- [ ] D1. 用户可按听原音、看文字精听、目标句跟读、替换说、评分结果的顺序完成单元。
- [ ] D2. 听原音步骤默认不展示完整文字稿。
- [ ] D3. 精听步骤支持逐句重听和同步高亮。
- [ ] D4. 替换说步骤不默认展示完整参考答案。
- [ ] D5. 用户至少完成一次替换说有效评分后，单元才标记为完成。
- [ ] D6. 跟读步骤评分可保存为历史记录，但不会单独触发单元完成。

## E. 口语评分

- [ ] E1. 用户可录音、试听、重录和提交评分。
- [ ] E2. 评分结果包含 0-100 总分。
- [ ] E3. 评分结果可包含发音相似度、流利度、完整度维度分。
- [ ] E4. 评分页提供示范音频或参考答案，并提供用户录音回放对比。
- [ ] E5. 系统不提供逐词纠错、语法批改和改正建议。
- [ ] E6. 评分记录区分 `target_sentence` 和 `speaking_prompt` 两种评分对象。

## F. 首页与复习

- [ ] F1. 首页展示可学习单元列表。
- [ ] F2. 登录用户首页展示继续学习入口。
- [ ] F3. 未完成单元点击后回到上次学习步骤。
- [ ] F4. 已完成单元提供再练一次入口。
- [ ] F5. 首页不展示社区、排行榜、支付、会员、营销 banner。
- [ ] F6. 普通用户不可见内部审核单元，内部测试账号可见内部审核单元并看到内部测试标识。

## G. 边界与异常

- [ ] G1. 音频播放失败时，用户不能进入依赖音频的跟读和替换说。
- [ ] G2. 麦克风权限缺失时，页面提示开启权限，单元不可完成。
- [ ] G3. 评分服务超时时，用户可重试且本地录音不丢失。
- [ ] G4. 登录过期时，用户可继续当前学习，但保存评分前需重新登录。
- [ ] G5. 导入失败时，后台展示明确失败原因。
